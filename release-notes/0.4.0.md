## The same Help menu as every app

- **What's New in SM Launcher Plus** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the SM Launcher Plus menu, greyed out when updates aren't available.
- Open each page with ⌘1–⌘4, even after closing the main window.
- **Show Log** (⌥⌘L) moved from the View menu to the Help menu.
